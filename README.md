# CoopRatings Agent

Appli Windows qui repère les jeux auxquels vous jouez et les ajoute toute seule à votre liste [CoopRatings](https://coopratings.duckdns.org), avec votre temps de jeu.

1. Téléchargez `CoopRatings-Agent.exe` dans la [dernière version](https://github.com/Batap2/coopratings-agent/releases/latest) et lancez-le (si Windows bloque : *Informations complémentaires* → *Exécuter quand même*).
2. Connectez-vous avec votre compte CoopRatings. C'est tout : l'appli démarre avec Windows et se met à jour seule.

## Vie privée

- **Envoyé au site** : le nom des jeux reconnus (ou de ce qui ressemble à un jeu, pour le vérifier), le jour et la durée de vos parties.
- **Jamais envoyé** : l'heure à laquelle vous jouez, les chemins et dossiers de votre PC, son nom, votre nom d'utilisateur Windows, les autres programmes ouverts.
